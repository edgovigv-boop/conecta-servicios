# Sonidos para Sistema Deportivo Pro Broadcast Studio

Coloca aquí archivos propios o libres de derechos de autor. No uses música comercial, NBA, ESPN ni audios de equipos reales.

Nombres esperados por `app.js`:

- `basket.mp3` — sonido de canasta normal o tiro libre.
- `triple.mp3` — sonido especial para triple.
- `whistle.mp3` — falta/silbato.
- `period.mp3` — fin de cuarto o cambio de periodo.
- `victory.mp3` — final del partido.

Si estos archivos no existen, la app usa Web Audio API como respaldo temporal con tonos generados en el navegador.
