# Conecta Servicios v6.2.0 - Home MVP social

## Idea aplicada

Esta versión sigue la idea del screenshot:

- Header blanco sobre fondo morado.
- Logo y nombre Conecta Servicios.
- Botón de campana arriba.
- Tres botones principales:
  - VENDO
  - OFREZCO
  - NECESITO
- Barra de búsqueda moderna.
- Feed visual con foto/video.
- Botones flotantes sobre la publicación:
  - corazón
  - mensaje
  - compartir
  - seguir
- Barra inferior con:
  - Inicio
  - Siguiendo
  - +
  - Mensajes
  - Perfil

## Reglas de esta versión

- Cualquier usuario puede publicar.
- El botón + abre la multimedia del dispositivo.
- Luego pasa a descripción + zona + categoría.
- La categoría solo puede ser:
  - VENDO
  - OFREZCO
  - NECESITO
- El usuario puede editar y borrar solo sus propias publicaciones.
- Se puede seguir a un proveedor, cliente o mensajero.
- En Mensajes se guardan los mensajes enviados desde publicaciones.
- Perfil permite guardar el nombre visible.
