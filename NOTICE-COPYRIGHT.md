# Aviso de copyright y protección — Conecta Servicios

Conecta Servicios es una plataforma digital en desarrollo para conectar personas, servicios, negocios locales, mandados, ventas, necesidades, envíos, viajes compartidos, mensajes internos y oportunidades.

Quedan protegidos:
- Código fuente.
- Diseño visual.
- Flujos de publicación.
- Sistema de mensajes.
- Modelo de edición y encuadre multimedia.
- Estructura de navegación.
- Textos, documentación y versiones.
- Marca, nombre comercial e identidad del producto.

Recomendaciones operativas:
1. Mantener GitHub en privado.
2. No compartir ZIP completo con terceros sin acuerdo.
3. No entregar llaves de Supabase ni variables de entorno.
4. No publicar service_role keys.
5. Registrar marca ante autoridad competente.
6. Preparar términos de uso y aviso de privacidad.
7. Usar NDA con inversionistas, desarrolladores externos o aliados.
8. Mantener historial de versiones y commits.
